# 柠柚API

柠柚API平台（https://api.nycnm.cn）整合插件，支持恶搞语音/踢球动图/答案之书/黑丝图片。

## 安装

在 LoyanBot 插件商店中搜索「柠柚API」即可安装。

## 使用

```
/设置key <key>       → 设置 API Key（仅主人可用）
/恶搞语音 <文本>     → 文字转趣味恶搞语音
/踢球 <QQ号>         → 踢球恶搞动图
/答案之书 <问题>     → 答案之书
/黑丝 <关键词>       → 随机黑丝图片（免费）
/语音 <文本>         → 同 /恶搞语音
```

## 安全

- API Key **仅主人**可通过 `/设置key` 设置
- Key 保存在本地 `storage/`，**不会上传仓库**
- 不提供查看 Key 的功能
