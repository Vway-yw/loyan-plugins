# 川普语录

随机川普名言

## 安装

在 LoyanBot 插件商店中搜索「川普语录」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/川普` | 🗽 随机川普语录 | 所有人 |
| `/川普语录` | 🗽 同 /川普 | 所有人 |
| `/trump` | 🗽 同 /川普 | 所有人 |

## 特点

- 🆓 免 key
- ⏱️ 智能缓存
