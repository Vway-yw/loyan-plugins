# 天气预报

查询城市天气实况与未来预报，免 key 实时数据。

## 安装

在 LoyanBot 插件商店中搜索「天气预报」即可安装。

## 使用

```
/天气              → 查询北京天气
/天气 上海         → 查询上海天气
/天气 广州 3       → 查询广州未来 3 天预报
/天气预报 深圳     → 同 /天气
```

## 命令列表

| 命令 | 说明 | 权限 |
|---|---|---|
| `/天气` | 🌤️ 查询北京天气 | 所有人 |
| `/天气 <城市>` | 🌤️ 查询指定城市天气 | 所有人 |
| `/天气 <城市> <天数>` | 📅 查询未来 1-5 天预报 | 所有人 |

## 数据内容

- 🌡️ 当前温度、体感温度
- ☁️ 天气状况（中文）
- 💧 湿度、风、降水、气压
- 📅 未来 1-5 天预报（温度范围+天气）

## 特点

- 🆓 免 key，wttr.in 数据源
- 🇨🇳 36+ 常用城市中英文映射
- ⏱️ 30 分钟缓存，请求轻量
