# UUID生成

生成 UUID v4

## 安装

在 LoyanBot 插件商店中搜索「UUID生成」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/uuid` | 🔑 生成 UUID（/uuid 5） | 所有人 |
| `/uuid生成` | 🔑 同 /uuid | 所有人 |
| `/uuid4` | 🔑 同 /uuid | 所有人 |

## 特点

- 💻 纯本地运行，无需网络
- ⚡ 即时响应
