# 啤酒百科

随机啤酒信息

## 安装

在 LoyanBot 插件商店中搜索「啤酒百科」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/啤酒` | 🍺 随机啤酒 | 所有人 |
| `/beer` | 🍺 同 /啤酒 | 所有人 |
| `/来瓶啤酒` | 🍺 同 /啤酒 | 所有人 |

## 特点

- 🆓 免 key
- ⏱️ 智能缓存
