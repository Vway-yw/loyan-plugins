# 星期计算

日期星期/相差天数

## 安装

在 LoyanBot 插件商店中搜索「星期计算」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/星期` | 📅 星期/日期差（/星期 2026-08-04） | 所有人 |
| `/星期几` | 📅 同 /星期 | 所有人 |
| `/weekday` | 📅 同 /星期 | 所有人 |

## 特点

- 💻 纯本地运行，无需网络
- ⚡ 即时响应
