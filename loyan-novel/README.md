# 小说阅读

小说搜索与阅读插件：搜索书名 → 选择书籍 → 章节阅读 → 翻页。

## 安装

在 LoyanBot 插件商店中搜索「小说阅读」即可安装。

## 使用

```
/小说 斗破苍穹      → 搜索书籍
/小说 1            → 选择第 1 本书（加载章节列表）
/小说 1 1          → 阅读第 1 本书第 1 章
/章节 5            → 直接阅读第 5 章
/下一页 /上一页    → 翻页（每页 500 字）
/尾页              → 最后一页
/第3页             → 跳转指定页
```

## 命令列表

| 命令 | 说明 | 权限 |
|---|---|---|
| `/小说 <书名>` | 🔍 搜索小说 | 所有人 |
| `/小说 序号` | 📚 选择书籍 | 所有人 |
| `/小说 序号 章节` | 📄 阅读指定章节 | 所有人 |
| `/章节 序号` | 📄 阅读当前书籍指定章节 | 所有人 |

## 特点

- 📚 全本小说搜索（10 万+ 书库）
- 📄 章节正文完整获取（Playwright 渲染，绕过反爬）
- 📖 500 字/页分页，翻页命令全局共用
- ⏱️ 正文 10 分钟缓存，加速重复阅读
