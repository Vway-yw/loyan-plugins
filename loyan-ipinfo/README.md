## 使用
# IP查询

查询 IP 归属地与网络信息。

## 使用

```
/ip            → 查询本机公网 IP
/ip 8.8.8.8    → 查询指定 IP
```

## 数据

- 国家/地区、城市、经纬度
- 运营商、时区

## 仓库

GitHub: https://github.com/Vway-yw/loyan-plugins


## 命令列表

| 命令 | 说明 | 权限 |
|---|---|---|
| `/ip` | 🌐 IP 归属地查询（/ip 8.8.8.8） | 所有人 |
| `/ipinfo` | 🌐 同 /ip | 所有人 |
| `/查询IP` | 🌐 同 /ip | 所有人 |

- 🆓 免 key
- ⏱️ 智能缓存
- 📱 适配 QQ 消息长度
