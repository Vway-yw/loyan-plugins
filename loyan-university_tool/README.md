# 大学查询

查询中国大学信息

## 安装

在 LoyanBot 插件商店中搜索「大学查询」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/大学` | 🎓 大学查询（/大学 随机 /大学 清华） | 所有人 |
| `/大学查询` | 🎓 同 /大学 | 所有人 |
| `/university` | 🎓 同 /大学 | 所有人 |

## 特点

- 🆓 免 key
- ⏱️ 智能缓存
