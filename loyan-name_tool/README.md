# 随机姓名

生成随机中文姓名

## 安装

在 LoyanBot 插件商店中搜索「随机姓名」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/名字` | 👤 随机姓名（/名字 男 /名字 女） | 所有人 |
| `/随机名字` | 👤 同 /名字 | 所有人 |
| `/随机姓名` | 👤 同 /名字 | 所有人 |

## 特点

- 💻 纯本地运行，无需网络
- ⚡ 即时响应
