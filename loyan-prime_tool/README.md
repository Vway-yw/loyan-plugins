# 质数工具

质数判断/分解/区间质数

## 安装

在 LoyanBot 插件商店中搜索「质数工具」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/质数` | 🔢 质数工具（/质数 17 /质数 分解 100） | 所有人 |
| `/素数` | 🔢 同 /质数 | 所有人 |
| `/prime` | 🔢 同 /质数 | 所有人 |

## 特点

- 💻 纯本地运行，无需网络
- ⚡ 即时响应
