# BMI计算

身体质量指数计算

## 安装

在 LoyanBot 插件商店中搜索「BMI计算」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/bmi` | 📊 BMI 计算（/bmi 65 175） | 所有人 |
| `/身体质量` | 📊 同 /bmi | 所有人 |
| `/体质指数` | 📊 同 /bmi | 所有人 |

## 特点

- 💻 纯本地运行，无需网络
- ⚡ 即时响应
