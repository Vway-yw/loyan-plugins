# 宝可梦图鉴

查询宝可梦信息

## 安装

在 LoyanBot 插件商店中搜索「宝可梦图鉴」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/宝可梦` | ⚡ 宝可梦查询（/宝可梦 pikachu /宝可梦 随机） | 所有人 |
| `/pokemon` | ⚡ 同 /宝可梦 | 所有人 |
| `/神奇宝贝` | ⚡ 同 /宝可梦 | 所有人 |

## 特点

- 🆓 免 key
- ⏱️ 智能缓存
