# 骰子硬币

掷骰子/抛硬币/随机数

## 安装

在 LoyanBot 插件商店中搜索「骰子硬币」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/骰子` | 🎲 掷骰子（/骰子 3 /骰子 2d20） | 所有人 |
| `/硬币` | 🪙 抛硬币 | 所有人 |
| `/随机` | 🎲 随机数（/随机 1 100） | 所有人 |
| `/掷骰子` | 🎲 同 /骰子 | 所有人 |
| `/随机数` | 🎲 同 /随机 | 所有人 |

## 特点

- 💻 纯本地运行，无需网络
- ⚡ 即时响应
