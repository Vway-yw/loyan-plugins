# 血型性格

血型性格与配对

## 安装

在 LoyanBot 插件商店中搜索「血型性格」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/血型` | 🩸 血型性格（/血型 A） | 所有人 |
| `/血型配对` | 🩸 同 /血型 | 所有人 |
| `/blood` | 🩸 同 /血型 | 所有人 |

## 特点

- 💻 纯本地运行，无需网络
- ⚡ 即时响应
