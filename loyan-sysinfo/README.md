# SysInfo_plugin

系统状态查询插件，展示机器人运行信息、系统资源占用

## 安装

在 LoyanBot 插件商店中搜索「SysInfo_plugin」即可安装。

## 命令列表

| 命令 | 说明 | 使用环境 | 权限 |
|---|---|---|---|
| `/运行状态` | 查看机器人运行时间、CPU/内存占用 | 群聊/私聊 | 所有人 |
| `/info` | 机器人基本信息 | 群聊/私聊 | 所有人 |
| `/status` | 机器人当前状态 | 群聊/私聊 | 所有人 |
