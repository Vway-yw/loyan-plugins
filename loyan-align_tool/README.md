# 文本对齐

文本居中/对齐显示

## 安装

在 LoyanBot 插件商店中搜索「文本对齐」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/对齐` | 📐 文本对齐（/对齐 你好） | 所有人 |
| `/居中` | 📐 同 /对齐 | 所有人 |
| `/center` | 📐 同 /对齐 | 所有人 |

## 特点

- 💻 纯本地运行，无需网络
- ⚡ 即时响应
