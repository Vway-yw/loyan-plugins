# Base64工具

文本与 Base64 互转

## 安装

在 LoyanBot 插件商店中搜索「Base64工具」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/base64` | 🔤 Base64 编解码（/base64 编码 hello） | 所有人 |
| `/b64` | 🔤 同 /base64 | 所有人 |

## 特点

- 💻 纯本地运行，无需网络
- ⚡ 即时响应
