# ROT13/凯撒

ROT13 与凯撒密码

## 安装

在 LoyanBot 插件商店中搜索「ROT13/凯撒」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/rot13` | 🔐 ROT13 变换（/rot13 hello） | 所有人 |
| `/凯撒` | 🔐 凯撒密码（/凯撒 3 hello） | 所有人 |
| `/caesar` | 🔐 同 /凯撒 | 所有人 |

## 特点

- 💻 纯本地运行，无需网络
- ⚡ 即时响应
