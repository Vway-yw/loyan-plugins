# 系统指令

Linux/Windows 常用实用指令查询，自动识别用户系统推送对应指令。

## 安装

在 LoyanBot 插件商店中搜索「系统指令」即可安装。

## 使用

```
/指令              → 查看使用帮助
/指令 linux        → Linux 常用指令
/指令 windows      → Windows 常用指令
/指令 网络         → 定向查询网络类指令
/指令 文件 / 进程  → 定向查询其他分类
```

自动识别：回复中包含 linux/ubuntu/windows 等关键词自动匹配系统。

## 指令库

- 🐧 **Linux**：系统信息、文件操作、权限、网络、进程、服务、包管理、磁盘（42 条）
- 🪟 **Windows**：系统信息、文件操作、网络、进程、系统管理、磁盘、修复、电源（36 条）

每条含命令、说明、分类，支持翻页查看。

## 命令列表

| 命令 | 说明 | 权限 |
|---|---|---|
| `/指令` | 🖥️ 系统指令查询 | 所有人 |
| `/指令 linux` | 🐧 Linux 常用指令 | 所有人 |
| `/指令 windows` | 🪟 Windows 常用指令 | 所有人 |
| `/指令 <分类>` | 🔍 定向查询（网络/文件/进程等） | 所有人 |
