# 年龄计算

根据生日计算年龄

## 安装

在 LoyanBot 插件商店中搜索「年龄计算」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/年龄` | 🎂 年龄计算（/年龄 1996-05-20） | 所有人 |
| `/周岁` | 🎂 同 /年龄 | 所有人 |
| `/age` | 🎂 同 /年龄 | 所有人 |

## 特点

- 💻 纯本地运行，无需网络
- ⚡ 即时响应
