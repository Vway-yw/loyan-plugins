# 罗马数字

阿拉伯/罗马数字互转

## 安装

在 LoyanBot 插件商店中搜索「罗马数字」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/罗马` | 🏛️ 罗马数字（/罗马 1999） | 所有人 |
| `/罗马数字` | 🏛️ 同 /罗马 | 所有人 |
| `/roman` | 🏛️ 同 /罗马 | 所有人 |

## 特点

- 💻 纯本地运行，无需网络
- ⚡ 即时响应
