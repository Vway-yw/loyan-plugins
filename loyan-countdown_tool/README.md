# 倒数日

记录重要日期并倒计时（本地存储）

## 安装

在 LoyanBot 插件商店中搜索「倒数日」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/倒数日` | 📅 倒数日（/倒数日 添加 生日 2026-10-01） | 所有人 |
| `/纪念日` | 📅 同 /倒数日 | 所有人 |

## 特点

- 💻 纯本地运行，无需网络
- ⚡ 即时响应
