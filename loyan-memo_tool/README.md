# 备忘录

简单文本备忘（本地存储）

## 安装

在 LoyanBot 插件商店中搜索「备忘录」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/备忘` | 📝 备忘（/备忘 添加 内容） | 所有人 |
| `/memo` | 📝 同 /备忘 | 所有人 |
| `/记一下` | 📝 同 /备忘 | 所有人 |

## 特点

- 💻 纯本地运行，无需网络
- ⚡ 即时响应
