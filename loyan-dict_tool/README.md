# 英语词典

英文单词释义查询（免费）

## 安装

在 LoyanBot 插件商店中搜索「英语词典」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/词典` | 📖 英文单词查询（/词典 hello） | 所有人 |
| `/dict` | 📖 同 /词典 | 所有人 |
| `/英语词典` | 📖 同 /词典 | 所有人 |

## 特点

- 🆓 免 key
- ⏱️ 智能缓存
