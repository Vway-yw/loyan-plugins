# 随机密码

生成随机安全密码

## 安装

在 LoyanBot 插件商店中搜索「随机密码」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/密码` | 🔑 生成随机密码（/密码 20 强） | 所有人 |
| `/随机密码` | 🔑 同 /密码 | 所有人 |
| `/生成密码` | 🔑 同 /密码 | 所有人 |

## 特点

- 💻 纯本地运行，无需网络
- ⚡ 即时响应
