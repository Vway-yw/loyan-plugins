# 汇率转换

实时汇率查询与货币转换，免key

## 安装

在 LoyanBot 插件商店中搜索「汇率转换」即可安装。

## 使用
# 汇率转换

实时汇率查询与货币转换，免 key。

## 使用

```
/汇率            → 常见货币兑人民币
/汇率 USD        → 美元兑人民币
/汇率 USD 100    → 100美元 = ?人民币
/汇率 USD EUR    → 美元兑欧元
/汇率 USD 100 EUR → 100美元 = ?欧元
```

## 数据

- 20+ 货币，1 小时缓存
- 支持任意货币对转换

| 命令 | 说明 | 权限 |
