# 随机颜色

生成随机颜色代码

## 安装

在 LoyanBot 插件商店中搜索「随机颜色」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/颜色` | 🎨 随机颜色 | 所有人 |
| `/随机颜色` | 🎨 同 /颜色 | 所有人 |
| `/color` | 🎨 同 /颜色 | 所有人 |

## 特点

- 💻 纯本地运行，无需网络
- ⚡ 即时响应
