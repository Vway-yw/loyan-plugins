# Kanye语录

随机 Kanye West 名言

## 安装

在 LoyanBot 插件商店中搜索「Kanye语录」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/kanye` | 🎤 随机 Kanye 语录 | 所有人 |
| `/侃爷` | 🎤 同 /kanye | 所有人 |
| `/kanye语录` | 🎤 同 /kanye | 所有人 |

## 特点

- 🆓 免 key
- ⏱️ 智能缓存
