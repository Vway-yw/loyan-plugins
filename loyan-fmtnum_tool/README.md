# 数字格式化

千分位/进制格式化

## 安装

在 LoyanBot 插件商店中搜索「数字格式化」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/千分位` | 🔢 数字格式化（/千分位 1234567.89） | 所有人 |
| `/格式化数字` | 🔢 同 /千分位 | 所有人 |
| `/formatnum` | 🔢 同 /千分位 | 所有人 |

## 特点

- 💻 纯本地运行，无需网络
- ⚡ 即时响应
