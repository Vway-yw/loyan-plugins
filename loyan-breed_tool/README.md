# 狗狗品种

狗狗品种查询/随机品种图片

## 安装

在 LoyanBot 插件商店中搜索「狗狗品种」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/犬种` | 🐶 随机犬种（/犬种 猎犬 指定） | 所有人 |
| `/狗狗品种` | 🐶 同 /犬种 | 所有人 |
| `/breeds` | 🐶 同 /犬种 | 所有人 |

## 特点

- 🆓 免 key
- ⏱️ 智能缓存
