## 使用
# 翻译

中英互译及多语言翻译（免费 MyMemory API）。

## 使用

```
/翻译 hello world    → 自动识别译成中文
/翻译 你好世界        → 自动识别译成英文
/翻译 en 你好         → 指定译成英文
/翻译 ja 你好         → 指定译成日语
```

## 支持语言

en/zh/ja/ko/fr/de/ru/es/it/pt/ar/th

## 命令列表

| 命令 | 说明 | 权限 |
|---|---|---|
| `/翻译` | 🌐 翻译（/翻译 hello world 自动中英互译） | 所有人 |
| `/translate` | 🌐 同 /翻译 | 所有人 |
| `/译` | 🌐 同 /翻译 | 所有人 |
