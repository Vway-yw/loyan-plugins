# 冷知识

随机有趣冷知识

## 安装

在 LoyanBot 插件商店中搜索「冷知识」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/冷知识` | 🤓 随机冷知识 | 所有人 |
| `/fact` | 🤓 同 /冷知识 | 所有人 |
| `/无聊事实` | 🤓 同 /冷知识 | 所有人 |

## 特点

- 🆓 免 key
- ⏱️ 智能缓存
