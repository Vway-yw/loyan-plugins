# 抽签

随机抽签（大吉/中吉/凶等）

## 安装

在 LoyanBot 插件商店中搜索「抽签」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/抽签` | 🎋 随机抽签 | 所有人 |
| `/签` | 🎋 同 /抽签 | 所有人 |
| `/运势签` | 🎋 同 /抽签 | 所有人 |

## 特点

- 💻 纯本地运行，无需网络
- ⚡ 即时响应
