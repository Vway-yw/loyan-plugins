# 表情符号

表情符号搜索/随机

## 安装

在 LoyanBot 插件商店中搜索「表情符号」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/表情符号` | 🎨 表情符号（/表情符号 动物） | 所有人 |
| `/emoji` | 🎨 同 /表情符号 | 所有人 |
| `/表情` | 🎨 同 /表情符号 | 所有人 |

## 特点

- 💻 纯本地运行，无需网络
- ⚡ 即时响应
