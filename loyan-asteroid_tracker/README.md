# 小行星监测

NASA 近地小行星数据查询

## 安装

在 LoyanBot 插件商店中搜索「小行星监测」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/小行星` | ☄️ 近地小行星监测（/小行星 3） | 所有人 |
| `/近地小行星` | ☄️ 同 /小行星 | 所有人 |
| `/asteroid` | ☄️ 同 /小行星 | 所有人 |

## 特点

- 🆓 免 key
- ⏱️ 智能缓存
