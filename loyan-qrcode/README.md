# 二维码生成

文本/链接生成二维码图片

## 安装

在 LoyanBot 插件商店中搜索「二维码生成」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/二维码` | 📱 生成二维码（/二维码 https://example.com） | 所有人 |
| `/qr` | 📱 同 /二维码 | 所有人 |
| `/生成二维码` | 📱 同 /二维码 | 所有人 |

## 特点

- 🆓 免 key
- ⏱️ 智能缓存
