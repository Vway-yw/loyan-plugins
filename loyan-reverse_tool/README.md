# 文本反转

文本反转/倒序

## 安装

在 LoyanBot 插件商店中搜索「文本反转」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/反转` | 🔁 文本反转（/反转 hello） | 所有人 |
| `/倒序` | 🔁 同 /反转 | 所有人 |
| `/reverse` | 🔁 同 /反转 | 所有人 |

## 特点

- 💻 纯本地运行，无需网络
- ⚡ 即时响应
