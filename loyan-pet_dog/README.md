# 随机狗狗

获取随机狗狗图片

## 安装

在 LoyanBot 插件商店中搜索「随机狗狗」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/狗狗` | 🐶 随机狗狗图片 | 所有人 |
| `/狗图` | 🐶 同 /狗狗 | 所有人 |
| `/随机狗狗` | 🐶 同 /狗狗 | 所有人 |

## 特点

- 🆓 免 key
- ⏱️ 智能缓存
