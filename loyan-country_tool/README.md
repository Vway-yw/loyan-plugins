# 国家信息

查询世界各国信息

## 安装

在 LoyanBot 插件商店中搜索「国家信息」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/国家` | 🌍 国家信息（/国家 中国 /国家 随机） | 所有人 |
| `/国家查询` | 🌍 同 /国家 | 所有人 |
| `/country` | 🌍 同 /国家 | 所有人 |

## 特点

- 🆓 免 key
- ⏱️ 智能缓存
