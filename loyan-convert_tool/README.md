# 单位转换

长度/重量/温度/速度单位换算

## 安装

在 LoyanBot 插件商店中搜索「单位转换」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/转换` | 📏 单位转换（/转换 100km m /转换 36.5c f） | 所有人 |
| `/换算` | 📏 同 /转换 | 所有人 |
| `/单位换算` | 📏 同 /转换 | 所有人 |

## 特点

- 💻 纯本地运行，无需网络
- ⚡ 即时响应
