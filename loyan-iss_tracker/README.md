# ISS定位

国际空间站实时位置

## 安装

在 LoyanBot 插件商店中搜索「ISS定位」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/iss` | 🛰️ 国际空间站实时位置 | 所有人 |
| `/空间站` | 🛰️ 同 /iss | 所有人 |
| `/国际空间站` | 🛰️ 同 /iss | 所有人 |

## 特点

- 🆓 免 key
- ⏱️ 智能缓存
