# 健身动作

随机健身动作推荐

## 安装

在 LoyanBot 插件商店中搜索「健身动作」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/健身` | 💪 随机健身动作 | 所有人 |
| `/健身动作` | 💪 同 /健身 | 所有人 |
| `/workout` | 💪 同 /健身 | 所有人 |

## 特点

- 🆓 免 key
- ⏱️ 智能缓存
