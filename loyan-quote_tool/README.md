# 人生格言

随机人生格言（本地库）

## 安装

在 LoyanBot 插件商店中搜索「人生格言」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/格言` | 📜 随机人生格言 | 所有人 |
| `/人生格言` | 📜 同 /格言 | 所有人 |
| `/座右铭` | 📜 同 /格言 | 所有人 |

## 特点

- 💻 纯本地运行，无需网络
- ⚡ 即时响应
