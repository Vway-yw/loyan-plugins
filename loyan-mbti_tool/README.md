# MBTI测试

简易 MBTI 性格测试（本地）

## 安装

在 LoyanBot 插件商店中搜索「MBTI测试」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/mbti` | 🧬 MBTI 测试（/mbti 开始，或 /mbti ENTJ） | 所有人 |
| `/性格测试` | 🧬 同 /mbti | 所有人 |
| `/mbti测试` | 🧬 同 /mbti | 所有人 |

## 特点

- 💻 纯本地运行，无需网络
- ⚡ 即时响应
