# 密码强度

检测密码强度

## 安装

在 LoyanBot 插件商店中搜索「密码强度」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/强度` | 🔐 密码强度检测（/强度 Abc123!） | 所有人 |
| `/密码强度` | 🔐 同 /强度 | 所有人 |
| `/strength` | 🔐 同 /强度 | 所有人 |

## 特点

- 💻 纯本地运行，无需网络
- ⚡ 即时响应
