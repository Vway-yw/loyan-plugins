# 哈希工具

MD5/SHA1/SHA256 文本哈希计算

## 安装

在 LoyanBot 插件商店中搜索「哈希工具」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/md5` | 🔐 计算 MD5 哈希（/md5 hello） | 所有人 |
| `/sha1` | 🔐 计算 SHA1 哈希 | 所有人 |
| `/sha256` | 🔐 计算 SHA256 哈希 | 所有人 |
| `/哈希` | 🔐 哈希工具入口 | 所有人 |

## 特点

- 💻 纯本地运行，无需网络
- ⚡ 即时响应
