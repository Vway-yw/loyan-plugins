# 斐波那契

斐波那契数列与黄金分割

## 安装

在 LoyanBot 插件商店中搜索「斐波那契」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/斐波那契` | 🔢 斐波那契（/斐波那契 10） | 所有人 |
| `/fib` | 🔢 同 /斐波那契 | 所有人 |
| `/黄金分割` | 🔢 同 /斐波那契 | 所有人 |

## 特点

- 💻 纯本地运行，无需网络
- ⚡ 即时响应
