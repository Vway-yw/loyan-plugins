# 纪念日

恋爱/纪念日天数计算

## 安装

在 LoyanBot 插件商店中搜索「纪念日」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/在一起` | 💑 在一起天数（/在一起 2023-01-01） | 所有人 |
| `/恋爱天数` | 💑 同 /在一起 | 所有人 |
| `/纪念` | 💑 同 /在一起 | 所有人 |

## 特点

- 💻 纯本地运行，无需网络
- ⚡ 即时响应
