# GitHub热门

查看 GitHub 热门仓库（日/周/月/按语言）

## 安装

在 LoyanBot 插件商店中搜索「GitHub热门」即可安装。

## 使用
# GitHub热门

查看 GitHub 热门仓库（日/周/月，可筛选语言）。

## 使用

```
/trending          → 今日热门
/trending 周       → 本周热门
/trending 月       → 本月热门
/trending python   → Python 热门
```

## 数据

- ★ Star 数、仓库名、描述、链接
- 时间范围：日/周/月
- 语言筛选

## 仓库

GitHub: https://github.com/Vway-yw/loyan-plugins


## 命令列表

| 命令 | 说明 | 权限 |
|---|---|---|
| `/trending` | 🔥 GitHub 热门仓库（/trending 周 /trending 月 /trending python） | 所有人 |
| `/github热门` | 🔥 同 /trending | 所有人 |
| `/github热榜` | 🔥 同 /trending | 所有人 |

## 特点

- 🆓 免 key
- ⏱️ 智能缓存
- 📱 适配 QQ 消息长度
