# 今日宜忌

今日宜忌与运势（本地算法）

## 安装

在 LoyanBot 插件商店中搜索「今日宜忌」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/宜忌` | 📅 今日宜忌 | 所有人 |
| `/今日宜忌` | 📅 同 /宜忌 | 所有人 |
| `/黄历` | 📅 同 /宜忌 | 所有人 |

## 特点

- 💻 纯本地运行，无需网络
- ⚡ 即时响应
