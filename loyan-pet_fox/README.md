# 随机狐狸

获取随机狐狸图片

## 安装

在 LoyanBot 插件商店中搜索「随机狐狸」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/狐狸` | 🦊 随机狐狸图片 | 所有人 |
| `/狐图` | 🦊 同 /狐狸 | 所有人 |
| `/随机狐狸` | 🦊 同 /狐狸 | 所有人 |

## 特点

- 🆓 免 key
- ⏱️ 智能缓存
