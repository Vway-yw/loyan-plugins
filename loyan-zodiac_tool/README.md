# 生肖查询

年份生肖查询

## 安装

在 LoyanBot 插件商店中搜索「生肖查询」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/生肖` | 🐉 生肖查询（/生肖 1996 /生肖 属马） | 所有人 |
| `/生肖查询` | 🐉 同 /生肖 | 所有人 |
| `/zodiac` | 🐉 同 /生肖 | 所有人 |

## 特点

- 💻 纯本地运行，无需网络
- ⚡ 即时响应
