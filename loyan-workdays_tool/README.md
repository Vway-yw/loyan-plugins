# 工作日计算

区间工作日统计

## 安装

在 LoyanBot 插件商店中搜索「工作日计算」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/工作日` | 📅 工作日统计（/工作日 2026-08-01 2026-08-31） | 所有人 |
| `/workdays` | 📅 同 /工作日 | 所有人 |
| `/上班天数` | 📅 同 /工作日 | 所有人 |

## 特点

- 💻 纯本地运行，无需网络
- ⚡ 即时响应
