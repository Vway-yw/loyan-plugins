## 使用说明

三个游戏热点插件（王者/和平/逃跑）和小说阅读共用翻页交互：
```
/王者热点          → 标题列表（带序号）
/王者热点 1        → 第 1 条正文第 1 页（每页 500 字）
/下一页 /上一页    → 翻页
/尾页 /第3页       → 跳页
```

## 安装

在 LoyanBot 插件商店中添加本仓库：

```
https://github.com/Vway-yw/loyan-plugins
```

商店采集后即可搜索安装各插件。
