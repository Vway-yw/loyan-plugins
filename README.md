# LoyanBot 插件合集

Vway-yw 开发的 LoyanBot 插件集合，共 6 个插件，每个插件独立维护。

## 插件列表

| 插件 | 目录 | 独立仓库 | 说明 |
|---|---|---|---|
| 象棋启动器 | `loyan-chess-start/` | [loyan-chess-start](https://github.com/Vway-yw/loyan-chess-start) | 检测象棋服务器是否正常运行 |
| 游戏插件 | `loyan-game/` | [loyan-game](https://github.com/Vway-yw/loyan-game) | 钓鱼/挖矿/打猎等小游戏，金币、经验、等级、排行榜 |
| MasterControl | `loyan-master-control/` | [loyan-master-control](https://github.com/Vway-yw/loyan-master-control) | 主人控制面板 - 群聊管理、跨群发消息 |
| Loyan配置 | `loyan-config/` | [loyan-config](https://github.com/Vway-yw/loyan-config) | 获取 LoyanBot 安装与配置过程 |
| SysInfo_plugin | `loyan-sysinfo/` | [loyan-sysinfo](https://github.com/Vway-yw/loyan-sysinfo) | 系统状态查询：运行信息、资源占用 |
| 表情包生成 | `loyan-sticker/` | [loyan-sticker](https://github.com/Vway-yw/loyan-sticker) | 互动表情包生成，支持自定义文字和模板 |

## 安装

每个插件在 LoyanBot 插件商店中按各自仓库安装即可。
