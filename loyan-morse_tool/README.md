# 摩斯电码

文本与摩斯电码互转

## 安装

在 LoyanBot 插件商店中搜索「摩斯电码」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/摩斯` | 📡 摩斯电码（/摩斯 编码 hello） | 所有人 |
| `/摩斯电码` | 📡 同 /摩斯 | 所有人 |
| `/morse` | 📡 同 /摩斯 | 所有人 |

## 特点

- 💻 纯本地运行，无需网络
- ⚡ 即时响应
