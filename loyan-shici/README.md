# 今日诗词

获取古诗词（按分类：山水/节日/爱情等）

## 安装

在 LoyanBot 插件商店中搜索「今日诗词」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/诗词` | 📜 随机诗词（/诗词 山水 指定分类） | 所有人 |
| `/古诗` | 📜 同 /诗词 | 所有人 |
| `/今日诗词` | 📜 同 /诗词 | 所有人 |

## 特点

- 🆓 免 key
- ⏱️ 智能缓存
