# 星座运势

星座运势与生日查星座（本地算法）

## 安装

在 LoyanBot 插件商店中搜索「星座运势」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/星座` | ♈ 星座运势（/星座 双子 /星座 1996-05-20） | 所有人 |
| `/星座运势` | ♈ 同 /星座 | 所有人 |
| `/horoscope` | ♈ 同 /星座 | 所有人 |

## 特点

- 💻 纯本地运行，无需网络
- ⚡ 即时响应
