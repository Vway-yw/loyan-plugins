# 随机头像

生成随机卡通头像

## 安装

在 LoyanBot 插件商店中搜索「随机头像」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/头像` | 🎨 随机头像（/头像 种子 自定义） | 所有人 |
| `/随机头像` | 🎨 同 /头像 | 所有人 |
| `/avatar` | 🎨 同 /头像 | 所有人 |

## 特点

- 🆓 免 key
- ⏱️ 智能缓存
