# 星战百科

查询星球大战角色/星球/飞船

## 安装

在 LoyanBot 插件商店中搜索「星战百科」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/星战` | 🚀 星战百科（/星战 角色 1 /星战 星球 1） | 所有人 |
| `/starwars` | 🚀 同 /星战 | 所有人 |
| `/星球大战` | 🚀 同 /星战 | 所有人 |

## 特点

- 🆓 免 key
- ⏱️ 智能缓存
