# 解梦

梦境解析（本地库）

## 安装

在 LoyanBot 插件商店中搜索「解梦」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/解梦` | 🌙 解梦（/解梦 水） | 所有人 |
| `/周公解梦` | 🌙 同 /解梦 | 所有人 |
| `/dream` | 🌙 同 /解梦 | 所有人 |

## 特点

- 💻 纯本地运行，无需网络
- ⚡ 即时响应
