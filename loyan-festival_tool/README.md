# 今日节日

今日节日查询

## 安装

在 LoyanBot 插件商店中搜索「今日节日」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/节日` | 🎉 今日节日查询 | 所有人 |
| `/今日节日` | 🎉 同 /节日 | 所有人 |
| `/festival` | 🎉 同 /节日 | 所有人 |

## 特点

- 💻 纯本地运行，无需网络
- ⚡ 即时响应
