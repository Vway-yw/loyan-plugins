# 卡路里

食物卡路里估算

## 安装

在 LoyanBot 插件商店中搜索「卡路里」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/卡路里` | 🔥 卡路里估算（/卡路里 米饭 200） | 所有人 |
| `/热量` | 🔥 同 /卡路里 | 所有人 |
| `/calories` | 🔥 同 /卡路里 | 所有人 |

## 特点

- 💻 纯本地运行，无需网络
- ⚡ 即时响应
