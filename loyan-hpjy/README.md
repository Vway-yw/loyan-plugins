# 和平精英热点

和平精英热点/爆料/攻略查询插件，从微信公众号搜索实时抓取，30 分钟自动刷新保证时效性。

## 安装

在 LoyanBot 插件商店中搜索「和平精英热点」即可安装。

## 命令列表

| 命令 | 说明 | 权限 |
|---|---|---|
| `/和平热点` | 🔫 查看和平精英最新热点 TOP10 | 所有人 |
| `/和平精英热点` | 同上 | 所有人 |
| `/和平资讯` | 同上 | 所有人 |
| `/和平爆料` | ⚡ 版本更新/新活动爆料 | 所有人 |
| `/和平更新` | 同上 | 所有人 |
| `/和平攻略` | 📖 通用攻略 | 所有人 |
| `/和平攻略 <内容>` | 📖 定向搜索（例：/和平攻略 枪械） | 所有人 |

## 特点

- ⏱️ 30 分钟缓存自动刷新，保证时效性
- 🔎 多关键词定向搜索（热点/爆料/攻略）
- 📱 来源：微信公众号实时搜索结果
