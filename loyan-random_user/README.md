# 随机用户

生成随机个人信息（测试/演示用）

## 安装

在 LoyanBot 插件商店中搜索「随机用户」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/随机用户` | 👤 生成随机用户信息 | 所有人 |
| `/假人` | 👤 同 /随机用户 | 所有人 |
| `/randuser` | 👤 同 /随机用户 | 所有人 |

## 特点

- 🆓 免 key
- ⏱️ 智能缓存
