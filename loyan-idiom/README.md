# 成语接龙

与机器人成语接龙游戏。机器人出题，你接龙，机器人再接，直到一方接不上。

## 安装

在 LoyanBot 插件商店中搜索「成语接龙」即可安装。

## 使用

```
/成语            → 开始成语接龙（机器人先出题）
/成语 提示       → 当前回合给一个提示
/成语 结束       → 结束游戏
直接回复四字成语   → 接龙（首字需与上句末字相同）
```

## 规则

- 四字成语，下一句首字 = 上一句末字（如：一马当先 → 先发制人 → 人山人海）
- 重复成语、非成语、接不上 判负
- 每回合限时 120 秒
- 连对 20 轮获胜

## 命令列表

| 命令 | 说明 | 权限 |
|---|---|---|
| `/成语` | 🎮 开始成语接龙 | 所有人 |
| `/成语 提示` | 💡 获取提示 | 所有人 |
| `/成语 结束` | 🏁 结束游戏 | 所有人 |

## 特点

- 📚 3 万+ 成语库（四字成语首字索引）
- 🤖 机器人自动接龙，接不上判你赢
- ⏱️ 限时机制，节奏紧凑
