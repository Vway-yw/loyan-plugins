# JSON格式化

JSON 格式化/校验

## 安装

在 LoyanBot 插件商店中搜索「JSON格式化」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/json` | 🔧 JSON 格式化（/json {"a":1}） | 所有人 |
| `/json格式化` | 🔧 同 /json | 所有人 |
| `/json校验` | 🔧 同 /json | 所有人 |

## 特点

- 💻 纯本地运行，无需网络
- ⚡ 即时响应
