# 字数统计

统计文本字数/字符/行数

## 安装

在 LoyanBot 插件商店中搜索「字数统计」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/字数` | 📊 字数统计（/字数 你好世界） | 所有人 |
| `/统计` | 📊 同 /字数 | 所有人 |
| `/wc` | 📊 同 /字数 | 所有人 |

## 特点

- 💻 纯本地运行，无需网络
- ⚡ 即时响应
