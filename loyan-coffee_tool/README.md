# 咖啡百科

随机咖啡知识

## 安装

在 LoyanBot 插件商店中搜索「咖啡百科」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/咖啡` | ☕ 随机咖啡 | 所有人 |
| `/coffee` | ☕ 同 /咖啡 | 所有人 |
| `/来杯咖啡` | ☕ 同 /咖啡 | 所有人 |

## 特点

- 🆓 免 key
- ⏱️ 智能缓存
