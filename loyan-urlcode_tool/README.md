# URL编解码

URL 编码/解码

## 安装

在 LoyanBot 插件商店中搜索「URL编解码」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/url` | 🔗 URL 编解码（/url 编码 你好） | 所有人 |
| `/url编码` | 🔗 URL 编码 | 所有人 |
| `/url解码` | 🔗 URL 解码 | 所有人 |

## 特点

- 💻 纯本地运行，无需网络
- ⚡ 即时响应
