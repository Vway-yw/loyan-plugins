# 大小写转换

文本大小写转换

## 安装

在 LoyanBot 插件商店中搜索「大小写转换」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/大小写` | 🔠 大小写自动转换 | 所有人 |
| `/大写` | 🔠 转大写 | 所有人 |
| `/小写` | 🔠 转小写 | 所有人 |
| `/case` | 🔠 同 /大小写 | 所有人 |

## 特点

- 💻 纯本地运行，无需网络
- ⚡ 即时响应
