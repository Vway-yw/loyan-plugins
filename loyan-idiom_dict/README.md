# 成语词典

常用成语查询（3000条，含释义）

## 安装

在 LoyanBot 插件商店中搜索「成语词典」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/成语词典` | 📖 成语查询（/成语词典 一马当先） | 所有人 |
| `/查成语` | 📖 同 /成语词典 | 所有人 |
| `/idiom` | 📖 同 /成语词典 | 所有人 |

## 特点

- 💻 纯本地运行，无需网络
- ⚡ 即时响应
