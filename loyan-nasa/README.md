## 安装

在 LoyanBot 插件商店中搜索「NASA每日一图」即可安装。

## 使用
# NASA每日一图

获取 NASA 每日天文图片与说明。

## 使用

```
/nasa            → 今日天文图片
/nasa 2026-08-01 → 指定日期
```

## 数据

- 高清天文图片（自动下载发送）
- 图片标题 + 说明

## 仓库

GitHub: https://github.com/Vway-yw/loyan-plugins


## 命令列表

| 命令 | 说明 | 权限 |
|---|---|---|
| `/nasa` | 🛰️ NASA 每日一图（/nasa 2026-08-01 指定日期） | 所有人 |
| `/每日一图` | 🛰️ 同 /nasa | 所有人 |
| `/天文` | 🛰️ 同 /nasa | 所有人 |
