# 计算器

数学表达式计算

## 安装

在 LoyanBot 插件商店中搜索「计算器」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/计算` | 🧮 表达式计算（/计算 (1+2)*3） | 所有人 |
| `/calc` | 🧮 同 /计算 | 所有人 |
| `/算一下` | 🧮 同 /计算 | 所有人 |

## 特点

- 💻 纯本地运行，无需网络
- ⚡ 即时响应
