# MasterControl

主人控制面板 - 群聊管理、跨群发消息

## 安装

在 LoyanBot 插件商店中搜索「MasterControl」即可安装。

## 命令列表

| 命令 | 说明 | 使用环境 | 权限 |
|---|---|---|---|
| `/群列表` | 查看机器人所在的所有群聊ID | 群聊/私聊 | 主人 |
| `/发群 <群ID> <消息>` | 向指定群发送消息（支持 reply:<消息ID> 或 qq:<QQ号>） | 群聊/私聊 | 主人 |
| `/set群名 <群ID> <名称>` | 给群设置备注名 | 群聊/私聊 | 主人 |
