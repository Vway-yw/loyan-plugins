# 时间工具

当前时间/时间戳转换/倒计时

## 安装

在 LoyanBot 插件商店中搜索「时间工具」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/时间` | 🕐 当前时间 | 所有人 |
| `/时间戳` | ⏱️ 时间戳转换（/时间戳 1750000000） | 所有人 |
| `/倒计时` | 📅 倒计时（/倒计时 2026-10-01） | 所有人 |
| `/现在时间` | 🕐 同 /时间 | 所有人 |
| `/几点` | 🕐 同 /时间 | 所有人 |

## 特点

- 💻 纯本地运行，无需网络
- ⚡ 即时响应
