# 多时区

世界主要城市时间

## 安装

在 LoyanBot 插件商店中搜索「多时区」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/时区` | 🌍 多时区（/时区 北京 /时区 纽约） | 所有人 |
| `/多时区` | 🌍 同 /时区 | 所有人 |
| `/timezone` | 🌍 同 /时区 | 所有人 |

## 特点

- 💻 纯本地运行，无需网络
- ⚡ 即时响应
