# 秒表

计时器

## 安装

在 LoyanBot 插件商店中搜索「秒表」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/秒表开始` | ⏱️ 开始计时 | 所有人 |
| `/秒表` | ⏱️ 查看耗时 | 所有人 |
| `/秒表结束` | ⏱️ 结束计时 | 所有人 |
| `/计时` | ⏱️ 同 /秒表 | 所有人 |

## 特点

- 💻 纯本地运行，无需网络
- ⚡ 即时响应
