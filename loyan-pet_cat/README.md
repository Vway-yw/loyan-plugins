# 随机猫咪

获取随机猫咪图片

## 安装

在 LoyanBot 插件商店中搜索「随机猫咪」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/猫咪` | 🐱 随机猫咪图片 | 所有人 |
| `/猫图` | 🐱 同 /猫咪 | 所有人 |
| `/随机猫咪` | 🐱 同 /猫咪 | 所有人 |

## 特点

- 🆓 免 key
- ⏱️ 智能缓存
