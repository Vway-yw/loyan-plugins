# Unicode工具

Unicode 编解码

## 安装

在 LoyanBot 插件商店中搜索「Unicode工具」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/unicode` | 🔤 Unicode 编解码（/unicode 编码 你好） | 所有人 |
| `/unicode编码` | 🔤 Unicode 编码 | 所有人 |
| `/unicode解码` | 🔤 Unicode 解码 | 所有人 |

## 特点

- 💻 纯本地运行，无需网络
- ⚡ 即时响应
