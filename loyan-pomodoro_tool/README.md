# 番茄钟

番茄工作法计时

## 安装

在 LoyanBot 插件商店中搜索「番茄钟」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/番茄开始` | 🍅 开始 25 分钟番茄钟 | 所有人 |
| `/番茄` | 🍅 查看剩余 | 所有人 |
| `/番茄结束` | 🍅 结束 | 所有人 |
| `/番茄钟` | 🍅 同 /番茄开始 | 所有人 |

## 特点

- 💻 纯本地运行，无需网络
- ⚡ 即时响应
