# 进制转换

十进制/二进制/八进制/十六进制互转

## 安装

在 LoyanBot 插件商店中搜索「进制转换」即可安装。

## 使用

| 命令 | 说明 | 权限 |
|---|---|---|
| `/进制` | 🔢 进制转换（/进制 255 16） | 所有人 |
| `/进制转换` | 🔢 同 /进制 | 所有人 |
| `/base` | 🔢 同 /进制 | 所有人 |

## 特点

- 💻 纯本地运行，无需网络
- ⚡ 即时响应
